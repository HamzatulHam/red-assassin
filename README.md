# 🔴 Красный асасин — игра-конструктор

Мини-раннер в стиле классических флеш-игр: красный ниндзя бежит не останавливаясь,
перепрыгивает овраги, запрыгивает на ворота и башни, лазает по стенам, собирает
мешочки с золотом и уворачивается от стражников (а прыжком на голову — обезвреживает их).

Написан на **чистом JavaScript + Canvas**, без сборки, фреймворков и зависимостей —
специально чтобы было удобно переделывать под себя.

---

## Запуск

Откройте `index.html` двойным кликом (рекомендуется Chrome или Edge).
Всё работает без сервера и без интернета.

- **Управление:** ПРОБЕЛ / клик / тап — прыжок (в воздухе — двойной прыжок),
  у стены герой залезает сам, прыжок на голову стражника обезвреживает его.
  `P` — пауза, `M` — звук.
- **Рекорд** сохраняется в браузере (localStorage).

## Что покрутить — `js/config.js`

| Хочу... | Крутите... |
|---|---|
| Перекрасить героя | `player.colors.*` (костюм, шарф, кожа…) |
| Быстрее бег | `player.speedStart`, `speedMax`, `speedGain` |
| Выше прыжок | `player.jumpV` ↑ или `gravity` ↓ |
| Двойной прыжок отключить | в `player.js` в блоке «расход буфера прыжка» |
| Больше золота | `world.coinChance`, `score.coinValue` |
| Больше оврагов / башен / стен | `world.gapChance` / `towerChance` / `wallChance` |
| Сложнее | `world.guardChance`, `world.gapMax`, `player.speedGain` |
| Охранники быстрее | `world.guardSpeed` |
| Свои тексты и надписи | `texts.*` (всё меню, экран смерти и т.д.) |
| Без звука по умолчанию | `sound: false` |
| Свои стартовые «звёзды» | `rating: { avg, votes }` |

## Костюмы, оружие, прокачка (магазин)

За собранные мешочки золота герой получает **золото в кошелёк** (сохраняется между
забегами). В меню и на экране результата есть кнопка **🛒 Магазин** с тремя вкладками:

- **Костюмы** — 7 скинов (цвета героя). Каждый костюм — это одна строка в
  `config.js → shop.skins`: id, название, цена и три цвета (`suit`, `suit2`, `scarf`).
- **Оружие** — кунай и сюрикен. Бросок — клавиша **X** (или кнопка 🎯 на экране).
  Параметры: `price`, `cooldown` (перезарядка), `speed` (скорость полёта),
  `pierce` (пробивает нескольких стражников).
- **Прокачка** — 4 линии с уровнями: Прыгучесть (+4% прыжка), Щиты (спасают от
  стражника), Магнит (притягивает золото), Кошелёк (+10% золота).
  Цена уровня считается как `base × step^уровень`.

Прогресс хранится в localStorage (`ra_save_v1`). Формулы и цены — всё в `config.js → shop`.

**Добавить свой костюм/оружие/прокачку** = дописать элемент в массив `skins` /
`weapons` / `upgrades` в config.js — магазин, цены и сохранение подхватят автоматически.

После правок обновите страницу (**Ctrl+F5**). Меняйте по одному параметру — так
понятно, за что отвечает каждое число.

## Как добавить своё препятствие

В `js/world.js` всё построено из «паттернов» — функций, которые добавляют кусок
уровня и сдвигают курсор `S.genX` вправо:

1. Скопируйте `patWall` и переделайте под себя (например, яма с шипами).
2. Добавьте шанс в `config.js → world` (например, `trapChance: 0.1`).
3. В `addPattern()` добавьте ветку: `if (r < сумма_шансов) return patTrap(...)`.
4. Если нужно особое рисование — добавьте вид блока в `World.draw()`.

## Как заменить героя / добавить скин

Отрисовка героя — целиком в `RA.Player.draw()` (`js/player.js`), это обычные
фигуры canvas: торс, капюшон, шарф, конечности. Цвета берутся из
`config.js → player.colors`, так что новый скин = новый набор цветов.

## Идеи для переделки

- Заменить двойной прыжок на рывок (dash) с неуязвимостью.
- Лучники на крышах, шипы в оврагах, катящиеся бочки.
- Босс-стражник каждые N метров.
- Магазин: скины и усиления за собранное золото.
- Настоящие «короткие уровни» с финишной чертой вместо бесконечного бега.
